# 第2回経営会議：成功報酬の上限設定

日付: 2026-04-24

## 議題
成功報酬（粗利20% + 上限設定）の詳細設計。

---

## 各チームの議論

### 経理チーム
- **評価**: 最も慎重に設計すべき領域
- **論点**: 粗利定義の曖昧性、心理的負担、継続取引時の累積額の膨張
- **提案**: 案件・年間・期間の3層で上限を設定。粗利は直接原価控除方式。貸倒リスクは共有。

### 営業チーム
- **評価**: 顧客との信頼関係に直結する最重要設計
- **論点**: 上限明示による交渉のしやすさ、沖縄の中小事業者の金額感度
- **提案**: 上限を前向きに訴求、上限到達後は3万円プランに移行誘導

### 商品企画チーム
- **評価**: 料金体系全体の整合性が問われる
- **論点**: 99円/3万円/成功報酬の関係の分かりやすさ、スコープ定義
- **提案**: 成功報酬発生条件と除外売上を明文化、3万円プランとの二重計上防止

### マーケティングチーム
- **評価**: 打ち出し方次第でブランドが大きく変わる
- **論点**: 誠実さの訴求、業界慣行（売上20%系）との差別化
- **提案**: 料金シミュレーター設置、「挑戦を止めない」コピー展開

### 技術チーム
- **評価**: 粗利トラッキングの仕組みが要
- **論点**: 売上・原価データの把握、長期追跡の運用負荷
- **提案**: Notion/Google Sheetsで案件別管理、LINE経由で月次簡易レポート回収

---

## 全体会議

### シナジー
- 全チーム「上限は設ける」で合意
- 上限を前向きに訴求することでブランドの誠実さを強調
- 経理の粗利定義 × 技術のトラッキング × 商品企画のスコープ定義で運用可能

### 対立点・トレードオフ
| 論点 | A案 | B案 |
|---|---|---|
| 案件上限 | 経理: 一律（安全） | 営業: 業種別 or 大型案件は柔軟に |
| 期間制限 | 経理: 12ヶ月で打ち切り | 営業: 継続取引は追いたい |
| 粗利定義 | 経理: 直接原価のみ控除 | 商品企画: 顧客にわかりやすく |

---

## 経営者の意思決定

| 項目 | 決定 |
|---|---|
| 基本料率 | 粗利20% |
| 案件上限 | 1案件あたり **30万円** |
| 年間上限 | 1顧客あたり年間 **200万円** |
| 対象期間 | 提案起点の取引成立から **12ヶ月間** |
| 粗利の定義 | 売上 − 直接原価（材料費・外注費・販売手数料・決済手数料） |
| 貸倒時 | 成功報酬発生しない（リスク共有） |
| 3万円プランとの併用 | 可（二重計上不可） |

---

## 成功報酬：最終設計

| 項目 | 内容 |
|---|---|
| 基本料率 | 粗利の 20% |
| 案件上限 | 1案件あたり 30万円 |
| 年間上限 | 1顧客あたり年間 200万円 |
| 対象期間 | 提案起点の取引成立から 12ヶ月間 |
| 粗利の定義 | 売上 − 直接原価（材料費・外注費・販売手数料・決済手数料） |
| 提案起因の判定 | 契約書に提案起因案件リストを明記、月次で双方合意 |
| 支払タイミング | 顧客の入金確認後、翌月末に請求書発行 |
| 貸倒時 | 顧客に入金なしの場合、成功報酬は発生しない |
| 3万円プランとの併用 | 可（同一案件の二重計上は不可） |
| 除外売上 | 既存顧客売上 / 独自ルート売上 / 会員同士の自然発生取引 |

## 業種別の目安（参考）

| 業種 | 典型的粗利率 | 売上100万円時の報酬 | 案件上限到達の売上目安 |
|---|---|---|---|
| 飲食 | 60〜70% | 12〜14万円 | 約214〜250万円 |
| 小売 | 30〜40% | 6〜8万円 | 約375〜500万円 |
| サロン | 70〜85% | 14〜17万円 | 約176〜214万円 |
| 映像制作 | 40〜60% | 8〜12万円 | 約250〜375万円 |

※いずれも案件上限30万円（＝粗利150万円で到達）

## マーケティングコピー案

- 「**成功したときだけ、お財布に優しい範囲でお支払い**」
- 「**1案件最大30万円。挑戦を止めないために、上限を設けました**」
- 「**粗利の20%、年間上限200万円。あなたのビジネスが伸びれば、私たちも伸びる。ただし、払いすぎない安心を**」
