# 粗利トラッキング Notion DB 設計

案件別に粗利・成功報酬・12ヶ月の追跡を一元管理するための Notion データベース設計。

---

## DB構成（3つのDatabaseで構成）

```
[DB1] 顧客マスタ (Customers)
         ↓ 1-to-many
[DB2] 案件マスタ (Cases)
         ↓ 1-to-many
[DB3] 月次売上 (Monthly Revenue)
```

---

## DB1: 顧客マスタ (Customers)

| プロパティ名 | 型 | 説明 |
|---|---|---|
| 顧客名 | Title | 会社名 |
| 業種 | Select | 飲食 / 小売 / サロン / 映像制作 / その他 |

| 契約開始日 | Date | 最初の契約日 |
| 担当者名 | Text | 社長 or 窓口 |
| LINE ID | Text |  |
| メールアドレス | Email |  |
| 電話番号 | Phone |  |
| 所在地 | Text | 沖縄県◯◯市 |
| 年間累計報酬 | Rollup | Casesから集計 |
| 年間上限残額 | Formula | 2,000,000 − 年間累計報酬 |
| ステータス | Select | アクティブ / 休止 / 解約 |

## DB2: 案件マスタ (Cases)

| プロパティ名 | 型 | 説明 |
|---|---|---|
| 案件名 | Title |  |
| 顧客 | Relation → Customers | 紐付け |
| 紹介先 | Text | 取引相手 |
| 提案日 | Date | 課題解決室が提案した日 |

| ステータス | Select | 進行中 / 上限到達 / 追跡終了 / 貸倒 |

## Views（推奨）

### Customersビュー
- **全顧客**: アクティブのみ、業種別グループ
- **年間上限近接**: 年間累計 > 150万円 でアラート
- **業種別**: 業種でグループ化

### Casesビュー
- **進行中の案件**: ステータス = 進行中
- **上限到達**: 上限到達 = true
- **今月追跡終了**: 追跡終了日が今月
- **顧客別**: Customerでグループ化

### Monthly Revenueビュー
- **当月分**: 対象月 = 今月
- **未確認**: 甲確認 or 乙確認 が未チェック
- **未入金**: 入金確認 = false
- **請求待ち**: 入金確認 = true AND 請求書発行日 = 空

## 自動化・通知

| トリガー | アクション |
|---|---|
| 月初1日 | 前月分のMonthly Revenue入力リマインド（LINE） |
| 年間累計 > 150万円 | 顧客ステータスにフラグ、営業にアラート |
| 追跡終了日の前月 | 追跡終了予告アラート |
| 上限到達 | 次の案件への誘導・10万円プラン提案リマインド |

## 数式リファレンス

### 案件報酬（上限適用後）
```
min(累計粗利 * 0.2, 300000)
```

### 残追跡月数
```
if(
  dateBetween(追跡終了日, now(), "months") > 0,
  dateBetween(追跡終了日, now(), "months"),
  0
)
```

### 年間上限残額
```
2000000 - 年間累計報酬
```
