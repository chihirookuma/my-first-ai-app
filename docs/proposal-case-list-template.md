# 提案起因案件リスト（月次合意用フォーマット）

成功報酬の対象となる案件を、甲乙（顧客と課題解決室）双方で月次合意するためのテンプレート。

---

## 運用フロー

```
【毎月最終営業日】
  ↓
乙（課題解決室）が当月の対象案件候補をリスト化
  ↓
甲（顧客）にLINEでPDF or スプレッドシートを共有
  ↓
翌月5営業日以内に甲が確認・修正
  ↓
双方で確定 → 請求書発行（翌月10日まで）
  ↓
入金確認 → 報酬支払（翌月末日）
```

---

### 案件上限適用ルール

1. 各案件について、粗利 × 20% を算出
2. 1案件で累計30万円に達した時点で、それ以降の当該案件の報酬は0円
3. 年初来累計が200万円に達した時点で、それ以降の全案件の報酬は0円
4. 未到達の案件は翌月以降も追跡（取引成立から12ヶ月間）

## 電子運用版（推奨）

LINE / Google Sheets / Notion での運用例：

### Google Sheets構成
- シート1: 当月明細（上記テーブル）
- シート2: 年間累計（自動集計）
- シート3: 12ヶ月追跡（案件ごとの経過月数）

### LINE運用
- 月次確定時にPDF化してLINE送付
- スタンプ1つで確認完了のライトな運用

### Notion運用
- Databaseで案件管理
- 顧客別ビュー / 月次ビューで切り替え
