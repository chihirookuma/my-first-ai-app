# 業種別ターゲットリスト（120社）テンプレート

営業チーム使用。業種別に各30社、計120社を3週間以内に埋める。

---

## リスト化の方針

- **地域**: 沖縄県内（那覇・浦添・宜野湾・沖縄市を優先、離島は後回し）
- **規模**: 従業員5〜30名程度の中小事業者
- **情報源**: 商工会議所名簿、ぐるなび、食べログ、Google Maps、業界団体、SNS
- **情報の質**: 会社名・業種・所在地・連絡先・接触経路（紹介者等）を最低限記載

## 接触優先順位の決め方

### Tier 1（最優先・今月接触）
- 紹介経由でアクセスできる会社
- 過去に接点があった会社
- 明確に課題を発信している会社（SNS・ブログ等で）

### Tier 2（来月接触）
- 商工会議所名簿から抽出
- 業界団体所属会社
- Google Maps / ホットペッパー等から評価の高い会社

### Tier 3（余力ある時）
- 飛び込み営業
- DM送付

## KPIとの紐付け

| KPI | 目標 | 逆算の目安 |
|---|---|---|
| 3万円プラン契約 | 5件/3ヶ月 | 成約率10%と仮定 |
| 99円プラン会員 | 100名/3ヶ月 | 面談からの登録率80% |
| 初回面談 | 50件/3ヶ月 | リストから面談化率42% |
| 初回接触 | 120件/3ヶ月 | リスト全量を3ヶ月で一巡 |

---

## 運用ルール

1. **毎週月曜**: 今週接触するリストをピックアップ（10〜15社）
2. **毎週金曜**: 接触結果を更新、翌週分を仕込み
3. **毎月末**: 全体のステータス更新、Tier見直し
4. **ステータスが1ヶ月動かない場合**: 「見送り」へ移動、理由を記録
