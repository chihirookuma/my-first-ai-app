# サービス定義書

課題解決室のサービス内容を明文化するドキュメント。顧客・協力者・社内で共有するための正式版。

---

## 1. 99円プラン（参加証）

### 提供価値
「誰に聞けばいいか迷う時間をゼロにする」沖縄の社長のための相談窓口。

### 月額
**99円／月（税抜）**

### 含まれる内容
| 項目 | 内容 |
|---|---|
| 月1回オンライン相談 | 1回30分（Zoom / Google Meet） |
| 事前アンケート | 相談前日までにLINE経由で送付 |
| 相談後フォロー | 翌営業日に「要点まとめ + 推奨アクション」1枚PDFを送付 |
| 会員コミュニティ | LINE公式アカウント内で他会員との情報交換 |
| ニュースレター | 月1回、課題解決事例・業界動向の配信 |

### 含まれないもの
- 無制限のチャット相談（3万円プラン以上）
- 営業代行・実行伴走
- 書類作成・契約書レビュー

### 予約ルール
- 予約はLINE経由で受付
- 前日までに日程確定
- **無断キャンセル時は翌月繰越不可**
- 日程変更は相談日の24時間前まで

### 解約ルール
- 月末までの申し出で翌月から解約
- 違約金なし

---

## 2. 3万円プラン（伴走型）

### 提供価値
「課題を発見するだけでなく、実行まで並走する」沖縄の社長の右腕。

### 月額
**30,000円／月（税抜）**

### 含まれる内容
| 項目 | 内容 |
|---|---|
| 月2回の1on1 | 1回60分、定例実施 |
| チャット相談 | LINE経由で平日営業時間内は無制限 |
| 週次実行伴走 | 毎週タスクレビュー（15分） |
| 月次レポート | 取り組み成果の可視化 |
| 会員コミュニティ | 全会員コミュニティへのアクセス |
| 優先マッチング | 会員間のコラボ提案を優先案内 |

### 対象業種（優先）
- 飲食
- 小売
- サロン
- 映像制作会社

### 含まれないもの
- 書類作成代行（別途見積）
- 営業同行（月2回まで追加なし、以降は別途）

### 契約期間
- 最低契約期間: **3ヶ月**
- 以降は月次自動更新
- 解約は前月末までの申し出

---

## 3. 上位プラン（10万円）

### 月額
**100,000円／月（税抜）**

### 含まれる内容
- 3万円プランの全機能
- 月4回の1on1（各60分）
- 営業同行（月2回まで）
- 重要取引先への提案書作成支援
- 優先対応（レスポンス24時間以内）

---

## 4. 成功報酬

詳細は `discussions/02-success-fee-structure.md` 参照。

| 項目 | 内容 |
|---|---|
| 基本料率 | 粗利の20% |
| 案件上限 | 1案件あたり30万円 |
| 年間上限 | 1顧客あたり年間200万円 |
| 対象期間 | 提案起点の取引成立から12ヶ月間 |
| 3万円プランとの併用 | 可（二重計上不可） |

---

## 5. プラン選択ガイド

| 顧客の状態 | 推奨プラン |
|---|---|
| まずは話を聞いてみたい | 99円プラン |
| 具体的な課題があり伴走してほしい | 3万円プラン |
| 経営全体を相談したい | 10万円プラン |
| 特定プロジェクトを実現したい | 3万円プラン + 成功報酬 |
