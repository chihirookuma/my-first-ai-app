# セットアップ手順（非エンジニア向け）

このフォルダは、本物のClaude AIを安全に呼び出すための「サーバー」プログラムです。
APIキー（お金がかかる秘密の鍵）をここに保管し、Webページ側には絶対に公開しません。

所要時間：**約30〜60分**　／　費用：**Cloudflare無料プラン＋APIの従量課金のみ**

---

## 全体の流れ

1. AnthropicでAPIキーを取得（10分）
2. Cloudflareアカウントを作成（5分）
3. パソコンに必要なツールを入れる（10分）
4. このフォルダをデプロイ（公開）する（15分）
5. WebページにサーバーのURLを貼り付ける（5分）

---

## ステップ1：AnthropicのAPIキーを取得

1. https://console.anthropic.com/ にアクセス
2. アカウントを作成 → メール認証
3. クレジットカードを登録し、**最低5ドル分**のクレジットを購入
   - ⚠️ 必ず「**Usage limits**」で**月の上限額**を設定してください（例: $10）
4. 左メニュー「**API Keys**」→「**Create Key**」
5. 表示されたキー（`sk-ant-api...` で始まる長い文字列）を**安全な場所にメモ**
   - ⚠️ このキーは**一度しか表示されません**。失くしたら作り直しになります

---

## ステップ2：Cloudflareアカウントを作成

1. https://dash.cloudflare.com/sign-up にアクセス
2. メールアドレスとパスワードで登録 → メール認証
3. ログインできればOK（無料プランで十分）

---

## ステップ3：パソコンにツールを入れる

### Node.jsをインストール

1. https://nodejs.org/ja にアクセス
2. 「**LTS**」と書かれた方をダウンロード → インストール
3. インストール後、「ターミナル」（Macは「ターミナル.app」、Windowsは「PowerShell」）を開いて、次のコマンドが動くか確認：

   ```sh
   node --version
   ```

   `v22.x.x` のような表示が出ればOK。

---

## ステップ4：このフォルダをデプロイ（公開）

### 4-1. ターミナルでこのフォルダを開く

```sh
cd ~/path/to/my-first-ai-app/worker
```

（`~/path/to/` はあなたのパソコン上の場所に置き換えてください）

### 4-2. 必要なファイルをダウンロード

```sh
npm install
```

数十秒待ちます。

### 4-3. Cloudflareにログイン

```sh
npx wrangler login
```

ブラウザが開きます → 「**Allow**」をクリック → ターミナルに戻ると「Successfully logged in」と表示されます。

### 4-4. APIキーをCloudflareに登録（秘密の鍵としてサーバーに保存）

```sh
npx wrangler secret put ANTHROPIC_API_KEY
```

→ プロンプトが出たら、ステップ1でメモしたAPIキー（`sk-ant-api...`）を貼り付けてEnter。

⚠️ このキーは**Cloudflareのサーバー内に安全に保管され、Webページからは見えません**。これが今回の「安全に運用する」仕組みの核です。

### 4-5. デプロイ

```sh
npm run deploy
```

初回は1〜2分かかります。完了すると、こんなURLが表示されます👇

```
https://post-generator-api.あなたの名前.workers.dev
```

このURLをコピーしてメモしておいてください。

---

## ステップ5：WebページにURLを貼り付ける

1. `post-generator.html` を開く
2. 30行目あたりにある以下の行を探す：

   ```js
   const API_URL = "";
   ```

3. ステップ4-5でメモしたURLを `""` の中に貼り付け：

   ```js
   const API_URL = "https://post-generator-api.あなたの名前.workers.dev";
   ```

4. ファイルを保存

これで完成です🎉

---

## 動作確認

`post-generator.html` をブラウザで開いて、テーマを入れて「生成する」を押してください。
10〜20秒ほどでAIが10個の投稿文を作ってくれます。

うまく動かないときは、ブラウザの「開発者ツール」→「Console」タブにエラーが出ていないか確認してください。

---

## 安全対策（既に組み込み済み）

- ✅ **APIキーはCloudflare内のみに保存**（Webページからは見えない）
- ✅ **同じIPアドレスから1分間に5回まで**の利用制限（連打や悪用を防止）
- ✅ **入力文字数を100文字以内に制限**（過剰な入力を防止）
- ✅ **AnthropicのUsage limitsで月額上限**（最終防衛ライン）

---

## さらに安全にするには

公開後、悪用のリスクを最小化したい場合：

1. **`worker.js` の `ALLOWED_ORIGIN`** を `"*"` から自分のサイトURL（例: `"https://yourname.github.io"`）に変更し、再度 `npm run deploy`
2. **AnthropicのUsage limits** を月$10など低めに設定
3. **より安いモデルに変更**：`worker.js` の `MODEL` を `"claude-haiku-4-5"` に変更すると料金が約1/5に

---

## よくある質問

**Q. 月にいくらかかりますか？**
A. 1回の生成で約$0.05〜0.08（Opus 4.7使用時）。1日10回なら月$15〜25程度。Haiku 4.5に変更すれば月$3〜5程度に抑えられます。

**Q. デプロイを取り消したい**
A. `npx wrangler delete` でWorkerを削除できます。

**Q. キーを更新したい**
A. ステップ4-4を再度実行すれば上書きされます。
